一、什么是 Quantumult X？

Quantumult X 是一款专注于网络规则分流与代理管理的高级工具。它的核心用途是：科学上网、网络加速、规则控制、流量监控、代理链路管理等。由于其强大的灵活性和稳定性，在 iOS 用户圈中广受推崇，尤其适合中高级用户或网络安全爱好者。

它不同于一般的 VPN 客户端，它更像一个小型的可编程网络路由器，你可以在里面设定谁走代理、谁走直连，甚至为不同的流量制定多级规则。这种“规则优先”的架构，让它在应对复杂网络环境时游刃有余。

二、为什么选择 Quantumult X？

在 iOS 平台上，类似的工具还有 Shadowrocket、Loon、Stash 等，但 Quantumult X 能脱颖而出，靠的正是其细腻的功能配置能力和稳定性极高的运行机制。

  • 流量分析：按时间、应用、节点等多维度进行网络使用统计。

五、规则与策略组：玩转分流的关键

Quantumult X 的灵魂，在于分流规则与策略组配置。这是它与普通 VPN 最大的差异。

5.1 什么是策略组？

策略组是一个“逻辑集合”，用来指示某类请求要使用哪种连接方式。常见的策略组包括：

  • 直连（DIRECT）：不通过代理，直接连接；

  • 全局代理（PROXY）：所有请求走代理节点；

  • 节点列表：列出多个节点供用户选择；

  • 自动选择（AUTO）：根据延迟或负载自动切换节点；

  • 拒绝（REJECT）：拦截特定流量，常用于广告屏蔽。

5.2 自定义规则分流

你可以根据域名、IP、应用名等创建详细规则。例如：

plaintext
DOMAIN-SUFFIX,google.com,PROXY
DOMAIN-SUFFIX,baidu.com,DIRECT
PROCESS-NAME,YouTube,PROXY

这些规则将自动应用在访问过程中，实现精准控制。

✅ 小贴士：建议使用“规则分组 + GEOIP + DOMAIN”组合，可以最大程度地控制代理策略，防止误杀或漏判。

七、使用中常见问题与解决方案

7.1 Quantumult X 无法连接？

  • 检查 VPN 权限是否授权；

  • 确保节点可用（ping 不通的换个节点）；

  • 检查配置文件是否正确生效。

7.2 VPN 状态频繁断开？

  • 避免开启低功耗模式；

  • 设置中允许后台活动；

  • 尽量使用稳定节点，不建议使用公共免费节点。

7.3 如何重置 Quantumult X？

在设置页中选择“恢复出厂设置”，即可清除所有配置，回归初始状态。

7.4 能否在一个设备上安装多个版本的 Quantumult X？

官方并未推出多版本，因此只能安装一个。若需切换配置，建议保留多个 .qxconfig 文件，根据场景导入即可。

FAQ

WinXray 延迟检测功能如何提高网络体验？
WinXray 会定期检测节点延迟，结合策略组自动切换到低延迟节点。保证网页、视频和游戏流量通过最佳节点，提高访问速度和连接稳定性，减少掉线和卡顿。
ShadowsocksR 支持哪些混淆插件？
ShadowsocksR 提供多种混淆方式，如 tls1.2_ticket_auth、http_simple、random_head 等。它们通过模拟正常流量特征来规避防火墙检测，使通信更加隐蔽。
Hysteria2 客户端延迟测试值不稳定怎么办？
可通过调整 Hysteria2 的 `recv_window` 与 `send_window` 参数改善传输性能，同时确保服务器带宽充足。若使用移动网络，建议启用 BBR 拥塞控制并降低测速频率以减少波动。
Netch 全局与规则代理如何合理选择？
全局代理适合游戏或全局科学上网，将所有流量通过节点；规则代理仅对指定应用或 IP 走代理，可提高带宽利用率和访问效率，根据使用场景灵活选择模式。
QuantumultX 的重写脚本可以实现哪些功能？
QuantumultX 支持 JavaScript 重写脚本，可修改请求头、响应内容、跳转 URL、广告屏蔽和定制化流量处理。结合策略组可实现个性化网络访问和优化，提高用户体验。
V2Ray QUIC 传输适合什么网络环境？
QUIC 基于 UDP 支持多路复用和零握手，降低延迟，提高吞吐量。适合高丢包、不稳定网络环境，可保证视频、游戏和即时通讯流量的稳定性和流畅体验。
如何给 Clash 或 Sing-box 添加本地广告屏蔽规则？
可导入公共广告域名列表（如 ads、trackers）并将其指向 `REJECT` 或 `DIRECT`（根据需求）；还可以使用 rule-provider 自动更新广告规则，并结合 hosts 或 DNS 层面进行联合拦截以提升屏蔽效果。
Matsuri 节点延迟排序功能如何使用？
Matsuri 定期测速节点延迟，并结合策略组自动选择延迟最低的节点。用户无需手动切换节点，即可保持高速访问，提高网页、视频和游戏体验的稳定性。
Trojan 的伪装域名为何重要？
伪装域名必须是真实可访问的网站，且证书有效。它用于伪装流量，使 Trojan 的数据在外观上完全像正常 HTTPS 请求，从而有效降低被封锁和 DPI 检测的风险。
Clash 的 Rule Provider 功能是干什么的？
Rule Provider 是 Clash 的规则订阅机制，它可以通过远程 URL 自动更新分流规则文件。这样用户无需手动修改本地配置，就能保持规则同步更新，例如广告过滤或流媒体分流。
